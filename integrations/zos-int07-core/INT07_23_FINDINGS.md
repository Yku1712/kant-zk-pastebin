| Release lifetime is an adapter contract | **High integration risk.** `AuthorizedSource` documents a guard or immutable release at [src/lib.rs:212](src/lib.rs#L212). The policy supplies a boolean at [src/lib.rs:228](src/lib.rs#L228), and dispatch follows later at [src/lib.rs:332](src/lib.rs#L332). `confirmed_receipt_does_not_bypass_revoked_public_release` verifies revocation before replay. Live revocation during dispatch is untested. | Bind the actual reader, release authority, tenant, revision, digest and destination to a release record whose validity covers submission. Preserve the tested fail-closed replay check. |
| Idempotent retry relies on a provider assertion | **High integration risk.** [src/lib.rs:251](src/lib.rs#L251) supplies a no-op default. [src/lib.rs:353](src/lib.rs#L353) can call an override after a lookup miss. `inconclusive_lookup_and_default_retry_issue_no_second_submit` verifies the default. Real Pastebin retry safety is unverified. | Keep the real destination lookup-only pending a trusted, durable idempotency contract. Bind retry capability to the configured destination. |
| Full IPFS and receipt provenance remain an external proof | **High integration risk.** [src/lib.rs:263](src/lib.rs#L263) delegates authentic receipt correlation and DAG verification. [src/lib.rs:395](src/lib.rs#L395) accepts an optional root and validates payload equality. `malformed_receipts_and_incomplete_readback_stay_unresolved` verifies refusals with fixture evidence. Live full-DAG reconstruction is blocked. | Require authoritative linkage between the complete operation and exact original bytes. If IPFS is required, require the expected root and verify every linked block and the reconstructed bytes before confirming. |
| Journal readers trust local receipt records | **Medium hardening.** [src/journal.rs:174](src/journal.rs#L174) checks the stored binding. [src/journal.rs:205](src/journal.rs#L205) parses the stored CID without reapplying the codec and multihash admissibility checks from receipt verification. [src/journal.rs:77](src/journal.rs#L77) lists pending bindings without a principal by design. Source inspection only. | Keep the database and journal API within the trusted operator boundary. Reuse structural CID validation on restore. Treat parse and schema errors as evidence requiring reconciliation. |
| Resource limits are delegated | **Medium hardening.** [src/lib.rs:206](src/lib.rs#L206) borrows the entire source body and [src/lib.rs:266](src/lib.rs#L266) accepts whole readback vectors. No standalone payload or evidence budget is enforced. Source inspection only. | Bound source, evidence and linked-block reads before allocating or hashing. Bound DAG work by total bytes, node count, depth and time. |

The [raw versus CRLF comparison](agent2/evidence/manifest-comparison.log) identifies the representation mismatch. | Generate the manifest from Git blob bytes or an exact-byte Git export. The Agent 2 branch contains a corrected manifest. |

Unauthorized fixture reads and mismatched authoritative tenants did not persist state. The checked SQLite errors returned without panic. These results cover the tested standalone boundaries. A process exit is distinct from a power-loss or filesystem durability guarantee.
